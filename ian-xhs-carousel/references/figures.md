# 代码画图

缺图的时候自己画。画出来要像这套界面里本来就有的插图：只用灰，最多带一处橙，几何精确，每根线都有来处。

## 风格

- **颜色只从变量里取**：用 `FigureKit.INK`，它会现读 `xhs.css` 里的变量，浅色深色都对。
  - `strong`：主线、主体
  - `body`：次要的线
  - `muted`：标注、箭头
  - `faint` / `line`：辅助线、网格
  - `fill` / `fillStrong`：浅色块
  - `accent`：要点名的那一处，整页（包括排版）只能有这一处
  - `accentSoft`：橙色的浅底
- **从真东西生成**：用真实数据、真实的 Logo 路径、真实的算法去画，不要手摆一个"看起来像"的。一组四宫格的效果图，最好是从同一个源（同一个 Logo、同一张照片）采样出来，放在一起才像一套
- **几何精确**：坐标取整到半像素，线宽统一（细线 1.5、主线 2.5、强调 4），间距用倍数
- **少**：一张图只说一件事。三个元素能说清楚就不用五个
- **字**：图里的标注用 22 或 24 号苹方，颜色 `muted`。图里不写大标题，标题交给卡片
- **不要**：剪贴画、emoji、立体投影、装饰渐变、发光、手绘风、随手挑的颜色、为了好看加的纹理

## 放哪

图总是放在一个"容器"里，看起来像界面的一部分：
- **卡片里的图槽** `.fig`：浅灰底，圆角 20。线稿、示意图、效果图都放这里。T04 的行尾小图、T09 的宫格图、T08 的前后图都是这个
- **窗口** `.chrome` + 图：网页、软件截图，或者代码画出来的整屏效果
- **手机** `.phone`：竖屏截图
- **对话框正文** `.dialog-body` 里放一个 `.fig`：封面主图

图槽里的图默认铺满（`object-fit: cover`）；图标、Logo 这类不能裁的东西加 `.fig--contain`。

## 常见图怎么画

**流程**：三到四个阶段横排，每个阶段一个小图加一行 22 号标签，中间用细线箭头连。几个阶段的图用同一个源，一步步变化。

**放大局部**：从大图里挑最有代表性的一块放大，被放大的那一块用一次橙。旁边可以留一个小的原图位置示意。

**图例 / 档位**：横排几个样本，下面标数值，从小到大或者从暗到亮。

**数据**：柱、点、线用 `fillStrong` 或 `body`，只有要比的那一个用橙。不画坐标轴框，只留基线；刻度字 22 号 `muted`。T13 的柱状图就是这个画法，可以直接用 HTML 写。

**对比**：左右两张用同样的构图、同样的大小，只改那一个变量。

**图标**：照 `xhs.js` 里那套，32 格，线宽 2.5，圆头圆角，只用线框。能用圆、圆角矩形、直线拼出来就不要用复杂路径。

## 写法

`<canvas>` 和内联 `<svg>` 都可以。canvas 适合画数据和大量重复的元素，svg 适合画图标和简单示意。

`assets/figure-kit.js` 里有几个小工具，复制到这期文件夹里引用：
- `FigureKit.prepare(canvas)`：按元素实际大小和设备像素比设好画布，返回 `{ ctx, w, h }`
- `FigureKit.INK`：当前主题下的颜色
- `FigureKit.onTheme(draw)`：先画一次，切到深色时自动重画。画图函数都用它包一下，`--theme dark` 渲染时才会是深色
- `FigureKit.arrow(ctx, x0, y0, x1, y1)`：细线箭头
- `FigureKit.label(ctx, text, x, y, opts)`：图里的标注
- `FigureKit.sampleImage(img, cols, rows)`：把一张图采样成亮度格（0 到 1），用来做"从真东西生成"的图

画图的函数放在一个 IIFE 里，常量和查表写在前面，调用放在文件最后（不然会碰到"用在定义之前"的报错）。canvas 绝对定位、铺满一个有尺寸的 `.fig`，`prepare` 会读它的实际大小。

演示状态（悬停、展开）用 `data-poke` 加 `poke` 事件触发，渲染脚本截图前会发这个事件。

用户给的现成图片如果有浅色和深色两版，就按主题切换：`<img data-light="a.png" data-dark="a-dark.png">`，在 `onTheme` 里换 `src`。

**一套图共用一个母题**：几页的配图尽量是同一个东西换角度、换大小、换裁切。比如封面放全貌，内页拆局部，结尾放成品。看起来是一组，也不用每页重新想。

**第一版往大了画**：代码画的图第一遍几乎总是偏小、四周发空。先按图槽的大小铺满去画，宁可被裁掉一截。
