# 交付前自查

先跑 `scripts/render.py`，它报的问题全部改掉。然后打开每页图和总览，逐条看。

## 整组
- [ ] 一页只讲一件事，删掉哪一页都会少点东西
- [ ] 总览里一眼看得出顺序和节奏，没有连续两页用同一个母版
- [ ] 封面缩到总览那么小，还看得清标题和主图
- [ ] 整组都是同一个主题（全浅或全深），没有混着来

## 每页
- [ ] 有底盘的页，底盘从标题组下面开始、铺出画布底边；T15 没有底盘，T19 的底盘从顶上垂下来
- [ ] 橙只有一处（栏目标签前的小圆点不算），用在这页最想让人看的东西上
- [ ] 标题断行自然，没有孤字，没有一行特别短
- [ ] 字号都在字号表里，没有为了塞下内容把字改小
- [ ] 卡片里的分区用细线隔开，卡片之间留 24
- [ ] 没有被裁到的字（窗口、手机、图可以出血，字不行）
- [ ] 内容区填得合适：不空得发虚，也不挤到底边
- [ ] 截图放在窗口、手机或者图槽里，线稿放在浅灰图槽里
- [ ] 没有留下虚线占位，用户还没给的图在交付时说清楚了

## 深色版（如果做了）
- [ ] 用 `--theme dark` 渲染，没有手写死的颜色在深色下变得刺眼或者看不见
- [ ] 代码画的图跟着换了颜色（用 `FigureKit.INK` 和 `onTheme`）
- [ ] 截图本身是浅色的话，考虑换成深色截图

## 配图
- [ ] 每张图单独拿出来也好看：截图清楚、裁得干净，Logo 和图标是矢量的，不糊不虚
- [ ] 不够好的图已经跟用户说了，没有拿凑数的图交差
- [ ] 从真数据、真路径、真逻辑画出来的
- [ ] 只用灰和那一处橙，线宽统一，标注 22 或 24 号
- [ ] 一组图共用一个母题

## 文案
- [ ] 口语，平实，像熟人讲给熟人听
- [ ] 没有先否后肯、排比、冒号结论、金句结尾、反转
- [ ] 英文能不用就没用（工具名、文件名除外）
- [ ] 副标题 20 字以内，卡片里的说明 15 字以内
