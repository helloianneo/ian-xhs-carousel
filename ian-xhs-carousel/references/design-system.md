# 设计规则

风格是一套产品界面的路子：锌灰中性色，只有一种橙色点题。白页面上垫一块灰底盘，内容做成一张张带分层阴影的卡片、窗口、对话框，像从一个真软件里截出来的。不用渐变，不用装饰图案，层次全靠底色深浅、阴影和字号来分。

所有值都写在 `assets/xhs.css` 的变量里。深色版只需要把 `<body>` 改成 `data-theme="dark"`，所有颜色和阴影都会跟着换，版式不用动。

规则分两层：固定层不动，守住这个风格；自由层可以放开，让每期长得不一样。

## 固定层（不动）

### 画布
- 1080×1440，内边距上 96、左右和下面各 80，内容宽 920
- 标题组和内容区之间的距离，默认 96（`.slide`），内容多时用 72（`.slide--tight`）

### 底盘
标题组下面那块灰色叫底盘（`.stage`）。它从内容上方 40 开始，左右各宽出 40，一直铺到画布底边外面，带一圈细边和大阴影。卡片都放在底盘上面。
- 底盘是这套风格最显眼的标志，大部分页都要有
- 观点页（T15）不要底盘，只留字
- 结尾对照页（T19）的底盘倒过来放：从画布顶边垂下来，托住上面那张图
- 一页只放一块底盘

### 字
中文用苹方，数字用 Inter，代码用 Geist Mono。Inter 和 Geist Mono 从 Google Fonts 加载，渲染时需要联网；断网时会退回苹方和 SF Mono，渲染脚本会提示。

| 类 | 规格 | 用在哪 |
|---|---|---|
| `.t-display` | 600 88/110，字距 −2% | 封面标题、观点页大字 |
| `.t-title` | 600 64/80，字距 −1% | 内页标题 |
| `.t-heading` | 500 40/52 | 卡片里的小标题（少用） |
| `.t-body` / `.sub` | 400 32/48 | 副标题、聊天正文 |
| `.t-strong` / `.row__head` | 500 32/48 | 条目标题、设置项名称 |
| `.t-caption` / `.row__note` | 400 26/40 | 条目说明、底栏说明 |
| `.t-label` / `.chip` / `.tag` | 500 24/32 | 栏目标签、标签、按钮 |
| `.t-small` | 400 22/36 | 时间戳、刻度、图里的标注 |
| `.t-num` | Inter 600 24/32 | 编号、计数 |
| `.t-metric` / `.t-metric-sm` | Inter 600 88 / 64 | 大数字 |
| `.t-code` / `.code` | Geist Mono 400 22/36 | 代码、提示词 |

字号只有 88 / 64 / 40 / 32 / 26 / 24 / 22 这几档，渲染脚本会查。一页只放一个 88 或 64 的标题。

### 颜色
文字分五级，由深到浅：`--text-strong`（标题、条目名）、`--text-medium`、`--text-body`（副标题）、`--text-muted`（说明）、`--text-faint`（最弱的提示）。

底色分几层：`--page` 是页面白，`--tray` 是底盘，`--surface` 是卡片，`--fill` 是卡片里的浅灰块（占位、标签、气泡），`--fill-strong` 比它再深一点。

**橙 `--orange` 一页只用一处。** 栏目标签前面那个小圆点每页都有，不算。橙色留给这一页最想让人看的那个东西，例如：
- 四宫格里推荐的那张卡（`.card--accent` 描边，加一个 `.tag--orange`）
- 柱状图里要比的那一根
- 观点页大字里的最后一行
- 时间线上"现在"那个点

截图上的一组编号标注（图上的编号和下面列表的编号）算一处，外层加 `data-accent`，脚本就会把它们当一处来数。

绿 `--green` 只用来表示"对、完成、上涨"（`.tag--green`、勾、开关），不当装饰色。

内容自带的颜色（品牌色、截图、照片）不算排版色，不受一页一处橙的限制。

### 卡片
- 卡片（`.card`）：2px 浅描边，圆角 32，阴影 `--shadow-card`
- 对话框和窗口（`.card--dialog`）：阴影更大更深，`--shadow-dialog`，看起来浮在底盘上面
- 卡片内部分区用 2px 细线隔开（`.split`），不要用间隙
- 卡片里的图圆角 20，小图标 20，手机屏 44
- 按钮、标签、编号这些小零件用 `--shadow-sm` 小阴影，或者不加阴影

### 间距
卡片之间 24，卡片里一行的内边距是上下 24、左右 36，宽松的行用 32/36。标题组内部：栏目标签到标题 32，标题到副标题 24。别的地方按 8 的倍数取。

### 文字
- 文字后面不垫色块（标签、气泡、按钮这类零件除外），不加描边和阴影
- 标题用 `<br>` 手动断行，不留孤字
- 一页的字，十秒内能读完

## 自由层（看内容放开）

母版是起点。下面这些可以按内容调：
- **出血**：窗口、手机、截图可以伸出画布底边被裁掉（T02、T11 本来就是这样），比硬塞进画布里好看
- **错落**：两台手机一高一低、几张卡片大小不一、通知卡下面再垫一张露个边
- **放大**：主角往大了放，配角缩小；截图可以只截局部再放大
- **换零件**：同一个母版里，行首可以是编号、勾、图标或者小图；行尾可以是标签、按钮、箭头，或者什么都不放
- **增减行数**：清单、时间线、列表一般三到五行，内容少就删几行，内容多就换成更紧凑的母版，不要把字号改小去硬塞

判断标准：把这页截出来，看着像不像某个精致软件的真实界面。只有排得整整齐齐的等分格子不是默认答案。

## 两种内容，两种放法

- **截图、照片、效果图**：放进窗口（`.chrome` 顶栏 + 图）、手机（`.phone`）或者卡片里的图槽（`.fig`），让它看起来是在一个真界面里显示
- **线稿、示意图、图标**：放进 `.fig` 浅灰图槽，和说明文字放在同一张卡里

## 常用类（`xhs.css`）

- 页面：`.slide`、`.slide--tight`、`.slide--center`、`.slide--end`
- 标题组：`.head`、`.head--center`、`.chip`、`.sub`
- 底盘：`.stage`、`.stage--fill`、`.stage--top`、`.stage--bare`
- 卡片：`.card`、`.card--dialog`、`.card--accent`、`.split`
- 卡片里的结构：`.bar`、`.foot`、`.chrome`、`.row`、`.row__text`、`.row__head`、`.row__note`
- 零件：`.btn(--primary/--round)`、`.tag(--green/--orange)`、`.badge(--orange/--soft/--green)`、`.pill`、`.ic`
- 图：`.fig`、`.fig--contain`、`.ph`（占位，换成真内容后删掉）
- 各母版自己的零件见 `xhs.css` 后半段，按 T01–T20 排

图标写成 `<i class="ic" data-i="check"></i>`，由 `xhs.js` 换成线框 SVG（32 格，线宽 2.5，圆头）。现有的图标有：close、check、cross、arrow-up、chevron-down、chevron-right、sparkle、info、copy、paperclip、code、search。要新增图标就在 `xhs.js` 的 `ICONS` 里加，画法照这套来。
