# Prompt Examples

下面这些可以直接复制使用。

## 一篇文章做成一组图

```text
/ian-xhs-carousel 把下面这篇文章做成一组小红书图文。
先出分镜表给我看，我确认了再排版。

<粘贴文章>
```

## 只要分镜表

```text
/ian-xhs-carousel 先别排版。
帮我看看下面这篇能做成几页小红书图，出分镜表就行。
每页写清楚：讲什么、用哪个母版、图上标题、副标题、配图从哪来。

<粘贴文章>
```

## 案例拆解

```text
/ian-xhs-carousel 我拆了一个网站的交互效果，素材和截图都在 ./case 文件夹里。
做成 5 页左右的小红书图：封面、原理、做法、效果、结尾。
原理那页的示意图帮我用代码画。
```

## 带截图的产品介绍

```text
/ian-xhs-carousel 我做了一个小工具，截图在 ./shots 里，下面是介绍。
做成一组小红书图，截图放进窗口或者手机里，看起来像真界面。

<粘贴介绍>
```

## 深色版

```text
/ian-xhs-carousel 把这篇做成小红书图文，用深色主题。
截图我都换成深色模式的了，在 ./shots-dark 里。

<粘贴文章>
```

## 同一组再出一版深色

```text
刚才那组图再出一版深色的，版式不用动。
```

## 改某一页

```text
第 3 页换成 T08 前后双栏，左边放旧版截图，右边放新版。
标题改成"改完以后少点了两步"。
```

## 页数太多，砍一砍

```text
这组图有点长，砍到 5 页。
留下最有用的几页，删掉的内容告诉我，我放进正文里。
```

## 想要一个母版里没有的排法

```text
/ian-xhs-carousel 我想要一页时间轴加前后对比：上面是时间轴，下面两张截图对比。
20 个母版里没有的话，用现有的卡片和零件拼一个，颜色字号别跑。
```
